Set up your Speldosa

You need Home Assistant with Music Assistant, a speaker that Music Assistant plays on, and a computer with Chrome or Edge. Takes about ten minutes.

1. Install the firmware

Connect the box to this computer with a USB-C data cable. Pick your box:

This browser cannot install firmware. Use Chrome or Edge on a computer. iPhone and iPad do not work. The page must be opened over https.

After installing you are asked for your Wi-Fi. Speldosa needs a 2.4 GHz network. The light pulses orange until it is connected, then blue until Home Assistant has added it.

No port in the list? Try another cable: many USB-C cables only charge.

2. Add the box to Home Assistant

  1. Home Assistant shows a notification: New devices discovered, Speldosa. Select Add. The light goes out when it is connected.
  2. Not shown after a minute? Settings, Devices and services, Add integration, ESPHome, and enter the box's address from your router.

3. Add the Speldosa integration

  1. In HACS, add this repository as a custom repository of type Integration, install Speldosa and restart Home Assistant.
  2. Settings, Devices and services, Add integration, Speldosa. Pick the box and the speaker it plays on.

4. Link the cards

  1. Put a new card on the box. It blinks and Home Assistant tells you about a new card.
  2. Open Speldosa, select Configure, then Link a card. Search for the album, playlist or audiobook, pick it, done. It starts playing.
  3. Lift the card: the music pauses. Put it back: it continues.

Lights: orange pulse, no Wi-Fi. Blue pulse, no Home Assistant. Green, playing. Dim orange, paused. Pink blink, card not linked yet. Red blink, could not play (Home Assistant says why).
